## 🚀 Featured Project

### 💊 Pharmacy System (C++)

A console application that simulates a real pharmacy visit:

1. The pharmacist asks the patient what they are suffering from.
2. The patient describes their condition.
3. The system suggests two medicine options: a **premium (higher price)** one and an **economy (lower price)** one.
4. The patient chooses the option that fits their needs and budget.
5. After the purchase, the program calculates and displays the **total bill**.
